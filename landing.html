XenonCode for VS Code

Write XenonCode — the language of Archean craft computers — in Visual Studio Code, powered by xenoncore: the same analyzer, vocabulary and reference docs the Archean blueprint app uses.

Install

  • Build the VSIX: git clone … && npm ci && npm run compile && npx @vscode/vsce package, then Install from VSIX in the command palette. Every push also uploads the VSIX as a CI artifact.

What you get

  • Red squiggles while typing: undeclared @functions, unknown calls, missing returns, duplicates — the analyzer that ships ZERO false positives on the shipped game disks.
  • Completion over the device vocabulary (input_number, output_text, screens, beacons…), project functions, $variables; hover with signature + description + origin; go-to-definition; document symbols.
  • The COMPILE function: XenonCode: Decompose Craft turns a craft blueprint.json (an in-game save) into craft.json + src/<disk>/*.xc real files; XenonCode: Pack Craft writes them back with byte surgery — every byte outside the edited program texts rides unchanged. Load the packed craft in-game; the computer reboots on it.
